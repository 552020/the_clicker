# Next.js App Contracts Overview

This document provides an overview of the files in `packages/nextjs/contracts`. For each file, you'll find:

- **File name and path**
- **Short description**
- **Usage**: Whether it is used in the app, and where (with file references)
- **Notes** (if relevant)

---

## deployedContracts.ts

- **Description**:
  - This file is autogenerated by Scaffold-ETH. It contains the addresses and ABIs of smart contracts that have been deployed by your project (e.g., TheClicker, YourContract), organized by chain ID.
  - Used by the frontend to know how to interact with your deployed contracts on different networks.
- **Used in**:
  - `hooks/scaffold-eth/useScaffoldReadContract.ts`
  - `hooks/scaffold-eth/useDeployedContractInfo.ts`
  - `hooks/scaffold-eth/useScaffoldContract.ts`
  - `hooks/scaffold-eth/useScaffoldWatchContractEvent.ts`
  - `hooks/scaffold-eth/useScaffoldWriteContract.ts`
  - `utils/scaffold-eth/decodeTxData.ts`
  - `utils/scaffold-eth/contract.ts`
  - `app/blockexplorer/address/[address]/page.tsx`
  - (autogenerated/updated by `hardhat/scripts/generateTsAbis.ts`)
- **Notes**:
  - Do not edit this file manually; it will be overwritten by deployment scripts.
  - If you redeploy contracts or add new ones, this file will update automatically.

---

## externalContracts.ts

- **Description**:
  - This file is for manually specifying addresses and ABIs of contracts deployed outside your project (e.g., DAI, USDC, or other third-party contracts you want to interact with).
  - The structure is similar to `deployedContracts.ts`, but is meant for external contracts.
- **Used in**:
  - `hooks/scaffold-eth/useScaffoldReadContract.ts`
  - `hooks/scaffold-eth/useDeployedContractInfo.ts`
  - `hooks/scaffold-eth/useScaffoldContract.ts`
  - `hooks/scaffold-eth/useScaffoldWatchContractEvent.ts`
  - `hooks/scaffold-eth/useScaffoldWriteContract.ts`
  - `utils/scaffold-eth/contract.ts`
- **Notes**:
  - You can safely edit this file to add new external contracts.
  - Example usage is provided in the file comments.

---

## General Notes

- Both files are used by Scaffold-ETH hooks to provide seamless contract interaction in the frontend.
- If you add or update contracts, make sure to redeploy or update these files as needed.
